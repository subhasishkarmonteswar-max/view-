# **App Name**: AuxCordocracy

## Core Features:

- Democratic Station Hosting: Hosts can initialize broadcast rooms using specific digit codes to lead a synchronized audio session for any connected guest.
- Join Booth Interaction: Remote users join using simple room codes and personal nicknames, creating a frictionless secondary-device entry point.
- Social Queue Integration: Direct submission of YouTube links into a collaborative pool that parses video IDs for automatic inclusion in the broadcast.
- Vibe Architect tool: A generative AI-powered tool that analyzes the lyrical sentiment of submitted tracks to suggest transition vibes and title themes for the current session.
- Real-time Consensus Voting: An instant scoring mechanism allowing users to upvote or downvote tracks, dynamically rearranging the play order based on real-time feedback.
- Master Dashboard Control: A unified interface for the host displaying a large-scale video player and a live-updated list of sorted competitor tracks.

## Style Guidelines:

- Primary color: Electric Neon Violet (#AE52FF) to evoke the vibrant energy of digital nightlife.
- Background color: Deep Onyx Amethyst (#100D13), which is a heavily desaturated version of the primary violet for a true midnight vibe.
- Accent color: Celestial Azure (#7A7AFF), providing a high-visibility contrast for interactive elements and state changes.
- Font pairing: 'Space Grotesk' for techno-scientific headlines and 'Inter' for high-precision body text and track descriptions.
- Linear glyphs with subtle cyan-to-violet glow effects, mimicking neon aesthetic motifs.
- A hierarchical dashboard layout that separates high-frequency controls for guests and mission-critical visualization for the host.
- Snappy transitions for queue re-ordering that emphasize real-time competition through smooth positional shifting.
